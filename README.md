## Building

## Interactive mode (optional)
```
python3 interactive.py
```
A menu lets you type a grammar, see FIRST/FOLLOW and the tables, parse strings with the LL(1) or SLR(1) parser (with an optional step-by-step trace), and evaluate the SDD of Item 3 one attribute at a time (press Enter to advance). The input/output required by the statement is still produced by `main.py` and `run_sdd.py`.

## Tests (optional)
```
python3 tests.py
```
Runs the examples of the statement, compares FIRST/FOLLOW and the number of LR(0) states with the book, checks the results of Item 3 (including the circular variant) and cross-checks both parsers against the language generated by brute-force derivations. It prints `ok` or `FAIL` for each check.

## Running Items 1 and 2
If you start `python3 main.py` from a terminal with nothing redirected, a menu lets you pick one of the examples or type your own grammar. When the input comes from a file or a pipe (as in the commands below), there is no menu and the output is exactly the one required by the statement.

```
python3 main.py < examples/ex1.txt
python3 main.py --sets < examples/ex2.txt
```
(On Windows the command may be `python main.py < examples\ex1.txt`.)

The input is the grammar (number of nonterminals, then one line per nonterminal)
followed by the strings to parse, one per line, ending with an empty line.
If the grammar is both LL(1) and SLR(1), the menu letters (T, B, Q) are read
from the same input, as in the statement.

Optional flags (they only add output, the default output is the one required):
- `--sets` prints the FIRST and FOLLOW sets (all First lines, then all Follow lines).
- `--tables` prints the LL(1) table, the LR(0) automaton and the SLR(1) table.
- `--trace` prints the stack/input/action table of each parsed string.

## Running Item 3
```
python3 run_sdd.py
```
Then type the strings, one per line, and finish with an empty line (for example `1234`, `7`, `12a`).
(On Windows the command may be `python run_sdd.py`.)

Options:
- `python3 run_sdd.py --graph` also prints the dependency graph.
- `python3 run_sdd.py --circular` uses the circular variant of the SDD (try the string `12`).
- `python3 run_sdd.py --parser slr1` parses with the SLR(1) parser (the default is LL(1)).

The grammar and the SDD are in `sdd_example.py`. For every string it prints
`no`, or the annotated parse tree, the evaluation order and `S.v`.
